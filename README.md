## Chapter-01 Type of CSS
+ external file - write css rule in seperate file with .css extension and link this file with HTML file in head tag.
+ style tag in head tag  - write css code in style tag in head tag.
+ Inline CSS - Write css with style attribute withn tag.

 + id selector has higher weightage than class selector and class selector has higher weightage than element selector.
